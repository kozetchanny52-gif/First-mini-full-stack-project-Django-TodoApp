# Django Todo App

## 📌 About

This is my first mini full-stack project built with **Django**.

The project started as a simple Todo application and helped me practice the core concepts of building a web application with Django — from models and database operations to forms, CRUD functionality, authentication, and user-specific data.

The main goal of this project was not just to build a Todo app, but to understand how the different parts of a Django application work together.

---

## 🚀 Features

- Create Todo tasks
- View Todo tasks
- Update Todo tasks
- Delete Todo tasks
- Mark tasks as completed or incomplete
- Add task categories/types
- Add deadlines
- Track task creation/update times
- Form validation
- User authentication
- Multiple users
- User-specific Todo tasks

Each user can manage their own tasks without accessing another user's Todo data.
