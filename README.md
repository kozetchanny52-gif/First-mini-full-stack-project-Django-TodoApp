# First Mini Full-Stack Project — Django Todo App

A mini full-stack Todo application built with Django.

## 🚀 Features

- Create tasks
- View tasks
- Update tasks
- Delete tasks
- Mark tasks as complete/incomplete
- Task categories and types
- Deadline tracking
- Created and updated timestamps
- Django forms and validation

## 🛠️ Technologies

- Python
- Django
- HTML
- CSS
- SQLite
- Git
- GitHub

⚙️ Installation
1. Clone the repository
git clone https://github.com/kozetchanny52-gif/First-mini-full-stack-project-Django-TodoApp.git
2. Enter the project
cd First-mini-full-stack-project-Django-TodoApp
3. Create a virtual environment
python -m venv venv
4. Activate the virtual environment

Windows:

venv\Scripts\activate
5. Install Django
pip install django
6. Apply migrations
python manage.py migrate
7. Start the development server
python manage.py runserver

Open:

http://127.0.0.1:8000/
